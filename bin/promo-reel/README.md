# Promo reel — 60-second showcase

Tooling that records a real WordPress instance using the Superdav AI Agent
plugin, then assembles a 60-second 9:16 reel suitable for Reels, TikTok and
Shorts.

## What's here

```
bin/promo-reel/
├── README.md          ← this file
├── script.md          ← human-readable storyboard + voice-over
├── prompts.json       ← machine-readable beat list (edit me to change the reel)
├── record.js          ← Playwright recorder — one .webm per prompt beat
├── assemble.sh        ← ffmpeg pipeline — title cards + clip stitching
└── output/            ← generated, gitignored
    ├── clips/         ← raw recordings (one .webm per beat)
    ├── segments/      ← per-beat MP4s (clips + title cards) used for concat
    └── superdav-ai-agent-reel.mp4
```

## Prerequisites

| Dep | Why | Check |
|---|---|---|
| Node ≥ 18 | Playwright recorder | `node --version` |
| Playwright Chromium | record sessions | `npx playwright install chromium` |
| ffmpeg | assembly + title cards | `ffmpeg -version` |
| jq | parse `prompts.json` in bash | `jq --version` |
| WordPress instance with this plugin active and a working AI provider connector | the prompts must actually run | open `wp-admin/admin.php?page=sd-ai-agent` and send a test message |

The recorder works against either `wp-env` (`http://localhost:8890`, default)
or the local dev install (`http://wordpress.local:8080`). Configure an AI
provider in **Settings → AI Credentials** before recording — without one, every
prompt will time out.

## Quick start

```bash
# 1. Make sure WordPress is up and a provider is configured.
npm run wp-env:start          # or use the dev install at :8080

# 2. Record every prompt beat (real AI calls — takes 5-15 minutes
#    depending on provider/model).
node bin/promo-reel/record.js

# 3. Assemble the reel.
bash bin/promo-reel/assemble.sh

# 4. Watch it.
xdg-open bin/promo-reel/output/superdav-ai-agent-reel.mp4
```

## Targeting a different site

```bash
# Local dev install
node bin/promo-reel/record.js \
    --base http://wordpress.local:8080 \
    --user admin \
    --pass admin

# wp-env default (no flags needed)
node bin/promo-reel/record.js

# Single beat only — useful when iterating
node bin/promo-reel/record.js --only 4-plugin

# Pin the model used for every beat (overrides whatever the chat UI
# would default to). Format is "<provider-id>:<model-id>" where the
# provider-id matches an entry returned by /wp-json/sd-ai-agent/v1/providers.
node bin/promo-reel/record.js --model openai:gpt-5.4-mini

# Skip the wp-login.php form (useful when WP Defender / a security
# plugin throttles login attempts on the dev install). Requires the
# `wp` CLI to be on PATH and pointed at the same install — the
# recorder mints a logged-in cookie directly via wp_generate_auth_cookie().
node bin/promo-reel/record.js --auth wp-cli --wp-cli /path/to/wp
```

Environment variables also work and are useful for CI: `WP_BASE_URL`,
`WP_ADMIN_USER`, `WP_ADMIN_PASSWORD`, `WP_AGENT_MODEL`.

### Auth modes

| Mode | Flag | When to use |
|---|---|---|
| Form login (default) | `--auth form` | Clean installs, wp-env, anywhere WP login isn't rate-limited. |
| wp-cli cookie mint | `--auth wp-cli` | Dev install with WP Defender (or any plugin that throttles `wp-login.php`); also faster — skips a full page load. |

## Customising the reel

Everything is driven from `prompts.json`. To change the reel:

1. Edit any beat's `prompt`, `caption`, or `duration_seconds`.
2. Re-record only the changed beat: `node bin/promo-reel/record.js --only <id>`.
3. Re-assemble: `bash bin/promo-reel/assemble.sh`.

To add a beat, insert a new object in `beats[]` with a unique `id`. Keep the
sum of `duration_seconds` at 60 for a true 60-second reel.

### Title cards

Beats with `kind: "title"` are generated by ffmpeg `drawtext` — no recording
needed. Fields: `headline`, `subhead`, `footer`.

### Prompt beats

Beats with `kind: "prompt"` are recorded live. The recorder waits up to
`wait.response_timeout_ms` (default 240 s) for the agent's run to finish, then
saves `output/clips/<id>.webm`. The assembler time-stretches each clip to
fit its `duration_seconds` slot — short responses slow down, long responses
speed up (which is what makes the reel feel snappy).

## Adding music

```bash
bash bin/promo-reel/assemble.sh --music ~/Music/license-cleared.mp3
```

The music is trimmed to the reel's length and replaces the silent AAC track.
Use only tracks you have a licence for.

## Troubleshooting

| Symptom | Fix |
|---|---|
| `record.js` times out on every beat | No AI provider configured. Test the chat manually first. |
| `record.js` fails on login | Check `WP_ADMIN_USER` / `WP_ADMIN_PASSWORD`. wp-env uses `admin` / `password`; the dev install uses `admin` / `admin`. |
| `wp-login.php` returns HTTP 429 with `Retry-After` | WP Defender (or similar) has locked the IP/account out. Switch to `--auth wp-cli` to skip the login form entirely. |
| Agent run returns `400 Bad Request - The reasoning_content in the thinking mode must be passed back to the API` | The selected model is a DeepSeek "thinking" variant that the plugin's agent loop doesn't replay. Pick a non-thinking model with `--model openai:gpt-5.4-mini` (or any OpenAI/Anthropic model). |
| Clip shows the WP admin bar / sidebar instead of just the chat | The recorder's chrome-hide init script didn't load (rare). Hard-refresh the chat in a real browser, confirm the chat panel itself renders correctly, then re-record. |
| `assemble.sh: no usable font found` | `apt install fonts-dejavu-core` (Debian/Ubuntu) or set `PROMO_FONT=/path/to/font.ttf`. |
| Clip looks tiny / letterboxed | Source aspect doesn't match 9:16. The assembler pads with black — change `viewport` in `prompts.json` to 9:16 (e.g. 540×960). |
| Final reel is silent on mobile preview | Some players require explicit audio. The assembler already adds a silent AAC stream — re-export with `--music` if your platform refuses silent uploads. |
| Want a slower reel | Bump per-beat `duration_seconds` and `output.duration_seconds` together. Add more `title` beats for breathing room. |

## How it fits together

```
prompts.json ──► record.js ──► output/clips/*.webm
                                       │
                                       ▼
prompts.json ──► assemble.sh ──► output/segments/*.mp4 ──► output/reel.mp4
                                  (title cards + clips)
```

`record.js` and `assemble.sh` are independent: you can record once and
re-assemble with new captions/durations/music without touching the browser.
